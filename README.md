# Degraded Traverse Records

Original synthetic corpus for combinatorial structure recovery from degraded raster evidence. Everything here is generated by `generate_raw.py`; no third-party imagery, measurement or label is included or redistributed.

## What a record is

A survey network of 13 stations was established and a route walked that visited every station exactly once. The route was drawn as straight legs between consecutive stations, then the plan degraded: on each leg one contiguous interior span faded away, leaving both ends attached but the middle missing. The station coordinates and the starting station survived. The visiting order did not.

Recovering that visiting order is the task.

## Reproducing the corpus

```
python generate_raw.py --out scenes.npz --report generation.json
```

The generator is deterministic under its fixed seed. `generation.json` records the seed, the shape of every array, the count of distinct rasters and the SHA-256 of the archive, so a rebuild can be checked byte for byte.

## Contents of `scenes.npz`

- `images` - `(3400, 72, 72)` `uint8`, the degraded plan raster
- `ports` - `(3400, 13, 2)` `float32`, station coordinates in pixel units
- `visit_order` - `(3400, 13)` `int8`, the true route
- `start_station` - `(3400,)` `int8`, the first station of the route
- `layout_id` - `(3400,)` `int32`, which of the 850 station layouts a record uses
- `raw_id` - `(3400,)` string, SHA-256 over the record's raster and coordinates

Each layout is reused for 4 independent routes, so a split that respects independence must keep whole layouts together.

## Scope

This is a controlled synthetic benchmark. It does not represent real survey plans, real drafting practice or real document degradation, and it must not be used as a source of geospatial measurement. `DATASET_CARD.md` states the intended use and the known limitations in full.
